# Foca Frenzy
Foca Frenzy is a small fish-catching game made with C++ and Windows Forms. Fish pop up all over the screen and you have to click them before they swin away. Let too many escape and it's game over.

![Foca Frenzy](https://cdn.hackclub.com/01a1700e-cda3-7d39-8c75-7a975cc8038f/captura_de_pantalla_2026-10-24_172713.png)

## How to run it
1. Go to the Releases section of this repository.
2. Download the file and unzip it if needed.
3. Open .exe and play.

## Made with
- C++/CLI and Windows Forms, in Visual Studio
- Pixel art, touched up in Aseprite
